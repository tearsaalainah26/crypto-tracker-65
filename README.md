# Crypto Tracker 65

Crypto Tracker 65 is a Python-based application designed to simplify the tracking of cryptocurrency prices and portfolios in real-time. With intuitive features, users can easily monitor their investments, set alerts for price fluctuations, and make informed decisions based on the latest market data.

## Features

- **Real-Time Price Updates**: Access current prices and historical trends for over 500 cryptocurrencies, ensuring that you stay informed of any market movements.
- **Customizable Portfolio Management**: Add, update, and manage your cryptocurrency investments efficiently; track profits and losses in real-time.
- **Price Alert Notifications**: Set thresholds for price movements, and receive instant notifications via email or SMS when significant changes occur.
- **User-Friendly Interface**: Designed with simplicity in mind, navigate through the app easily and find all the features you need without hassle.

## Installation

To get started with Crypto Tracker 65, follow these installation steps:

1. Clone the repository to your local machine:
   ```bash
   git clone https://github.com/your_username/crypto-tracker-65.git
   ```

2. Navigate to the project directory:
   ```bash
   cd crypto-tracker-65
   ```

3. Create a virtual environment (optional but recommended):
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows use `venv\Scripts\activate`
   ```

4. Install the required packages:
   ```bash
   pip install -r requirements.txt
   ```

## Basic Usage Example

To start tracking your favorite cryptocurrencies, simply run the application:

```bash
python main.py
```

Once the application is running, follow the prompts to enter your cryptocurrency investments and set your desired alerts. You will then receive ongoing updates regarding your portfolio.
